# Windows 一键配置与启动

适用于 Windows 10/11 **x64**，不需要 Codex、预装 Python、Node.js、PowerShell 7 或手动编辑 PATH。Windows 自带的 PowerShell 5.1 是入口运行环境；系统安全策略禁止运行脚本、网络无法下载依赖或磁盘不可写时，会停在实际失败阶段，不显示为安装成功。

## 新客户

1. 下载完整 `SkillCollect-v0.2.4-Windows-OneClick.zip`，完整解压到一个可写的新文件夹，例如 `D:\SkillCollect`。不要在压缩包预览里直接运行。
2. 双击 `一键配置并启动.cmd`。首次会检测、下载并准备缺失依赖；保留窗口，查看实际步骤，首次下载可能需要几分钟。
3. 安装完成后自动打开 `http://127.0.0.1:8765`。在工作台本地设置模型，再粘贴链接分析。无需模型密钥也能启动和管理资料。
4. 以后双击同一个文件启动。使用期间保留启动窗口；按 `Ctrl+C` 停止。

## 已有模型配置和资料

1. 先关闭原工作台启动窗口，保留原项目文件夹。
2. 把新包解压到另外的新文件夹。第一次双击 **`沿用旧资料并启动.cmd`**。
3. 在本机目录选择窗口中选择原项目文件夹（里面有 `data\app.sqlite3`），或直接选择原资料目录（里面有 `app.sqlite3`）。不要只选择某一个数据库或密钥文件。
4. 新版本直接使用原资料目录，并在新项目 `.runtime/data-location.json` 记录目录指针。原数据库、媒体、模型设置、`.secrets.key` 和 `secrets.enc` 都留在原处，不打包、不上传、不搬动。
5. 以后双击普通 `一键配置并启动.cmd` 即会沿用该目录。不必重新填写模型和飞书密钥。原项目文件夹仍是资料所在位置，不能删掉。

这不是跨电脑凭证迁移。把代码包复制到另一台电脑不会附带原电脑资料或密钥；也不要为了省事把私人 `data` 目录发给别人。若原资料使用自定义目录，选择该目录或沿用 `SKILL_COLLECT_DATA` 环境变量。

## 自动准备的内容

| 内容 | 如何准备 |
|---|---|
| Python | 优先复用兼容的本机解释器；缺失时下载 CPython 维护者在 NuGet 发布的便携包，放入项目专属目录，不运行全局安装器 |
| Node.js/npm | 优先复用兼容版本；缺失时下载 Node.js 官方便携 ZIP |
| FFmpeg/FFprobe | 检查两个程序均可运行；缺失时下载 FFmpeg 官网列出的 Gyan 固定版本 Windows 构建 |
| Python 库 | 只安装到项目虚拟环境，使用仓库固定版本清单与 PyPI |
| 前端与 Playwright | 使用项目 npm 锁文件，依赖安装到项目 `frontend/node_modules` |
| Chromium | 由项目锁定的 Playwright 从官方来源安装，使用独立匿名访问上下文，不读取系统浏览器登录 |

下载文件的版本、来源和 SHA-256 记录在 `scripts/windows-runtime-lock.json`。验证不一致就拒绝使用；不自动改到未知镜像、不关闭 TLS 证书验证、不修改系统或用户全局 PATH、注册表、执行策略或代理配置。入口的执行策略参数只作用于本次启动进程。

便携运行时只下载到本机 `.runtime`，发行 ZIP 不捆绑这些第三方二进制。各运行时保留上游许可；Gyan FFmpeg 使用 GPLv3，其许可和对应源码入口见下载目录及上游站点。项目 MIT 许可不改变它们各自的许可。

## 进度与故障恢复

- 窗口显示当前阶段；没有实际可计量下载时不编造百分比。失败会保留阶段与说明，重新双击可以复用已验证的依赖。
- 未成功准备环境时，不初始化或改写原数据库。正常启动后的数据库兼容迁移仍按应用版本执行。
- 同一项目的配置流程使用排他锁；不会同时安装两份，也不会结束其他程序。端口被不属于本项目的程序占用时明确停止。
- 首次需要能访问 NuGet、Node.js 官方站、Gyan、PyPI、npm 与 Playwright 官方下载源。后续视频与模型使用还需要各自服务的网络。
- “环境就绪”只证明本机依赖可用，不等于所有抖音视频、模型、GitHub 或飞书均已真实联通。需要按任务的音画、转写、来源及分析结果验收。

只读检查（不会下载、安装、创建数据库或读取密钥）：

```powershell
powershell.exe -NoProfile -File scripts/windows_bootstrap.ps1 -CheckOnly -Json
```

只准备环境、不启动服务：

```powershell
powershell.exe -NoProfile -File scripts/windows_bootstrap.ps1 -NoStart
```

本次 Windows 原生执行、重新运行、资料保留与源码/发布范围按 `docs/验收报告.md` 的实际证据记录；客户自身网络上的原片分析仍需单独实测。
