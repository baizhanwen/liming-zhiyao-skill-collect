# v0.1.2 飞书完整同步与真实上传视频验收（预发布）

本轮完成用户授权飞书专用表的18步真实双向同步，并验证了15.3秒自制上传视频经真实MiniMax ASR、4张抽样画面理解及DeepSeek分析保存知识。文字来源链路沿用已通过的真实Easel固定版本记录。抖音自动抓取仍因当前网络Fake-IP受限，原抖音片内容没有验收，整体外部目标没有据此宣称完成。

修复与实现：

- 飞书跳过默认空行；读回按实际字段规范化摘要，不把模型状态或应用自填时间当远端真相。企业存在多个个人副本时要求选择具体目标，保留其他副本。
- 新增或更新收到ACK后标记待确认，重新读取完整记录、写入字段及附件文件哈希，全部一致才保存同步基线。超时、限流或无法确认时保留不确定状态，不盲目创建重复记录。
- 显式刷新企业完整包后，表格正文、ZIP正文及个人正文一致；直接改企业正文后的普通导入仍不自动写回。真实测试覆盖去重、个人更新、双边冲突、选择本地/企业版本、附件恢复和多个副本。
- 精确官方MiniMax主机使用原生ASR接口，兼容模型服务继续独立配置；文字、视觉、转写不自动复制模型或密钥。
- 画面证据的界面标签显示为抽样画面观察，保留后端原始结果。侧栏版本直接取package元数据。

验证边界：

- 本机139项pytest通过（含本地媒体与显式连接器契约），构建通过。5项UI完整历史结果为1项真实本地API流程加4项显式界面契约；其后只重跑受影响的1项标签回归，不把它记成第6项新测试或全套重新运行。
- 真实飞书成功记录保留18步结果、内容/包/文件哈希和清理状态；两轮实际失败、诊断修复与清理记录保留，不覆盖成成功。只测试独立标记的自编资料，原有记录保持不变；公开证据不含企业标识、密钥或素材。
- 15.3秒视频是自制固定样例，4帧OCR、背景和时间经人工核对；不是逐帧观看或总体准确率。ASR品牌“利明智耀”误识别为“利明制药”，2字同音错保留，不能声称逐字全对。
- 三平台CI结果、代码SHA和链接将在实际通过后写入本说明和验收报告。CI不会调用真实付费模型、企业飞书或重新获取抖音视频。

项目仍默认本机单用户。飞书是带摘要复查的乐观并发，未核实远端原子CAS；不自动传播删除或清除未绑定素材。旧版tag和发行保留，v0.1.2为独立预发布。
