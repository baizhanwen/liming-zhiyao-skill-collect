# 利明智耀 skill clloect 使用说明

安装与日常使用   2026年11月4日

本说明面向第一次使用工作台的用户。安装完成后，在浏览器里粘贴 GitHub 或抖音链接，查看分析结果，再按需要保存成个人技能，并同步到公司的飞书技能库。

日常顺序是：启动工作台 → 配置模型 → 粘贴链接分析 → 保存个人技能 → 按需同步企业技能。

## 先确认你拿到的版本

本说明对应 **v0.2.5**。分析结果和来源证据保留在「任务记录」，用户点击「保存为个人技能」后生成并保存草稿。个人技能可继续与飞书企业技能库手动同步。

升级后，工作台左下角应显示 `v0.2.5`。如果仍显示旧版本，先停止旧启动窗口，再从新文件夹启动并刷新页面。旧 v0.2.4 包中的「生成 Skill 草稿」对应新版的「保存为个人技能」。

## Windows 首次安装

1. 确认电脑是 Windows 10 或 Windows 11 的 x64 系统。可在「设置 → 系统 → 系统信息」查看系统类型。

2. 打开下方下载页面，下载 SkillCollect-v0.2.5-Windows-OneClick.zip。

[打开 Windows 一键安装包下载页面](https://github.com/baizhanwen/liming-zhiyao-skill-collect/releases/tag/v0.2.5)

3. 右键压缩包，选择「全部解压缩」。建议解压到固定、可写的新文件夹，例如 D:\SkillCollect。打开解压后的文件夹，找到「一键配置并启动.cmd」。

4. 双击「一键配置并启动.cmd」。首次会自动检查并准备 Python、Node.js、视频处理工具和项目依赖。保留窗口并等待安装结果，首次下载可能需要几分钟。

5. 完成后浏览器会打开 http://127.0.0.1:8765。若没有自动打开，把这个地址复制到浏览器地址栏。

Windows 一键包使用系统自带的 PowerShell。使用过程中保留启动窗口；以后双击同一个文件即可再次启动。若下载失败，记下窗口里的失败步骤，网络恢复后重新运行。

## Mac 安装与启动

Mac 当前使用安装脚本。首次需要准备运行环境，之后只需启动项目。已安装好并且能打开工作台的用户，可直接看本节最后一部分。

### 第一步 准备运行环境

安装 Python 3.11 或更高版本，以及 Node.js 24。Python 推荐使用项目说明中列出的 3.12 或兼容版本。请从官方网站选择 macOS 安装包，安装后重新打开「终端」。

[Python 官方 macOS 安装包](https://www.python.org/downloads/macos/)

[Node.js 官方下载页面 选择 24 系列](https://nodejs.org/en/download)

如果要分析视频，还需要 FFmpeg 和 FFprobe。它们用于提取音轨和画面。已安装 Homebrew 的电脑可在终端执行下面这一行；尚未安装 Homebrew 时，可按其官网流程安装，或由安装维护人员准备视频工具。

```sh
brew install ffmpeg
```

[Homebrew 官方安装说明](https://brew.sh/)

在终端逐行执行下面的命令。能看到版本文字，说明对应工具可以被项目找到。

```sh
python3 --version
node --version
npm --version
ffmpeg -version
ffprobe -version
```

### 第二步 下载并安装项目

1. 打开项目仓库，点击绿色「Code」按钮，再点击「Download ZIP」。解压后把项目文件夹放到固定位置。

[打开项目仓库](https://github.com/baizhanwen/liming-zhiyao-skill-collect)

2. 打开「终端」，先输入 cd 和一个空格，再把解压后的项目文件夹从访达拖入终端，按回车。这样就进入了正确目录。

3. 依次执行下面两行。第一行安装项目依赖并构建页面，第二行启动工作台。

```sh
bash scripts/setup.sh
bash scripts/start.sh
```

4. 在浏览器打开 http://127.0.0.1:8765。使用时保持终端窗口运行，结束后按 Control+C 停止。

### 以后怎样启动

进入同一个项目文件夹，只执行 bash scripts/start.sh。安装脚本通常只在首次安装或更新项目后运行。浏览器页面依赖本机服务，关闭终端后需要重新启动才能使用。

## 首次配置模型

工作台使用你自己配置的模型服务。先配置文字分析，再根据视频使用需求配置图片理解和语音转写。配置项只在本机填写。

| 配置卡片 | 用途 | 什么时候需要 |
| --- | --- | --- |
| 文字分析 | 理解项目和材料、生成技能草稿、继续追问 | 分析链接和保存生成草稿时 |
| 图片理解 | 识别视频抽取画面的内容和文字 | 需要理解视频画面时 |
| 语音转写 | 把视频里的讲话变成文字 | 需要分析视频声音时 |

### 照着这五步填写

1. 打开左侧「设置与诊断」，找到「自配模型」。

2. 在对应卡片填写 Base URL、API Key 和模型名称。Base URL 是供应商提供的接口根地址，通常到 /v1；模型名称需要与供应商支持的名称完全一致。

3. 如果供应商的文字、图片和语音接口地址不同，分别填写。一个文字模型测试通过，只能说明文字接口可用。

4. 点击页面上方「保存全部设置」。更换密钥时填写新值；已经配置的密码框留空通常表示保留原密钥。

5. 分别点击「测试文字分析」「测试图片理解」「测试语音转写」，查看每张卡片返回的结果。遇到错误时，先按提示核对地址、模型权限和账户额度。

### 怎样向模型供应商确认参数

可以询问供应商：我的账户可使用哪一个文字模型、图片理解模型和语音识别模型？它们各自的 API 根地址是什么？是否兼容本工作台支持的接口？订阅是否覆盖这些调用？

测试和正式分析都会向配置的服务发出请求，费用和额度由模型供应商规定。企业材料是否可以发给该服务，应先按公司的数据使用要求确认。

### 先做一次小范围检查

建议先分析一个公开 GitHub 仓库，确认文字分析正常，再提交一段较短的视频检查语音和画面能力。到「任务记录」打开结果，核对它使用的是源码、字幕、音频转写还是抽样画面。

遇到「需要配置模型后继续」，补全设置后回到原任务，点击「重试 / 继续」。已经获取的来源材料会保留在任务里。

## 分析链接与查看进度

### 分析 GitHub 项目

1. 进入「工作台」，粘贴完整 GitHub 仓库链接。也可以粘贴仓库内目录或文件的链接。

2. 选择「快速了解」或「深入分析」，点击「开始探索」。第一次了解项目可先用快速模式。

3. 在任务详情查看当前阶段，完成后阅读「是什么」「能用来做什么」「如何开始」等内容。

4. 切换到「来源与证据」核对文件和引用。需要继续了解时，打开「继续追问」，输入你的问题。

### 分析抖音视频

1. 在抖音里复制视频的分享文案，将整段文案粘贴到工作台输入框。保留其中的 https://v.douyin.com/… 链接即可。

2. 点击「开始探索」。工作台会尝试获取公开原片、处理音轨和抽样画面，再调用已配置的模型分析。正常入口只需要粘贴分享内容。

3. 查看结果中标注的分析依据。视频提到 GitHub 项目时，查看关联卡片中的明确链接或搜索候选，核对引用后再进入候选项目。

当前采集使用公开访问方式。视频被删除、设为私密或受到平台和网络限制时，可能无法取得原片。任务会保留具体失败阶段，此时可以稍后重试，或用下方备用上传补充自己有权使用的视频或字幕。

### 上传本机视频或字幕

点击「上传视频或字幕」，选择文件后提交。常见视频格式包括 MP4、MOV、MKV、WEBM，字幕包括 SRT、VTT，文本支持 TXT。文件上限为 100 MB，媒体时长上限为 20 分钟。仅上传字幕时，结果会注明基于字幕。

### 怎样判断仍在运行

查看任务上方的阶段、耗时、尝试次数和最近状态更新时间。网络请求内部进度不一定有百分比，单看耗时不能判断卡住。可点击「刷新状态」查看最新情况，失败后根据错误提示处理，再点「重试 / 继续」。

离开任务页后，可以从左侧「任务记录」重新打开。重复点击首页提交会创建新任务；继续同一次分析应优先使用原任务的操作按钮。

## 个人技能与发现 Skill

### 从分析结果保存个人技能

1. 分析完成后，先阅读结果，决定是否值得保存。

2. 点击「保存为个人技能」。工作台使用文字模型生成草稿并保存。再次打开同一个任务时，可点击「查看个人技能」打开原草稿。

3. 进入「个人技能」，把名称和简介改得容易理解。简介建议交代它解决什么问题、需要什么输入、最后能得到什么。

4. 检查「技能正文」里的适用条件、前置条件、执行步骤、输出和验收方法，点击「保存技能」。

例如名称可写「把抖音视频拆解成脚本结构」，简介可写「输入一条有权访问的视频或字幕，整理开头、中段、结尾和可借鉴的表达方式，供改写脚本参考」。实际能力应与正文和所需工具一致。

### 在 GitHub 上发现现成 Skill

1. 打开「发现 Skill」，输入你要完成的任务。勾选模型整理时，会把搜索需求发给已配置的文字模型。只想按关键词搜索时，可以取消勾选。

2. 首轮没有结果时，工作台会最多补查一组原始关键词或常用别名，例如把「抖音分析」回退为 douyin analysis。结果上方显示实际查过的词。如果仍没有相关候选，可以尝试较短或分开的关键词，或在「扫描仓库地址」直接粘贴已知的 GitHub 仓库链接。

3. 从候选仓库点击扫描，阅读发现的 SKILL.md、附属文件和许可说明。一个仓库可能包含多份技能，逐项勾选后点「导入所选技能」。

搜索结果是本次查询的候选，不能覆盖 GitHub 上的所有技能。搜索命中也不表示技能已适配你的电脑。导入后的正文和文件可以在个人技能中查看。

### GitHub Token 怎样填写

Token 是 GitHub 的个人访问令牌。公开仓库搜索可以留空；配置后可增加对 SKILL.md 文件的代码搜索。按官方页面创建细粒度令牌，只授予所需读取权限，再填入「设置与诊断 → GitHub Token」，保存并测试。

[GitHub 官方个人访问令牌说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)

### 保存后怎样使用

在个人技能详情点「导出完整包」可得到 ZIP，交给你使用的 AI 工具按其安装说明接入。导入工作台后可以审阅、编辑、导出和企业同步；实际执行效果需要在对应工具与环境中验证。

## 个人技能与企业技能同步

「个人技能」保存在你的电脑里。「企业技能」连接公司授权的飞书多维表格。同步前先预览变化，确认后再执行。

### 已经配置好飞书的用户

1. 先打开个人技能，检查名称、简介和正文，保存修改。

2. 进入左侧「企业技能」，切换到「同步个人技能」。

3. 勾选要上传的技能，点击「预览同步变化」。核对本次是新增、更新还是内容一致。

4. 确认后点击「确认并执行本次同步」。查看下方「本次操作结果」，并可在「同步日志」里检查详细结果。

5. 切回「企业技能」标签，点击「读取企业技能」或「刷新企业技能」，确认已上传内容。

### 把企业技能保存到个人库

在「企业技能」标签读取团队记录，勾选需要的技能，点击「导入所选个人副本」。之后可以在个人技能里编辑和导出。个人副本的修改需要再次预览并确认同步，才会写入企业表。

### 两边都修改过怎么办

同步预览可能提示冲突。先展开个人版本和企业版本，比较内容，再选择保留个人版本、保留企业版本或另建个人副本。处理所有冲突后再执行。遇到失败时先看逐项结果和同步日志，再进行下一次预览。

如果在飞书里直接修改了正文，预览可能提示完整包需要刷新。确认这次同步后，工作台会按当前企业内容刷新附件。

### 尚未配置飞书时需要谁准备

请企业管理员或有权限的维护人员准备企业自建应用、目标多维表格及可编辑授权。普通用户拿到 App ID、App Secret、表格链接和 Table ID 后，在本机设置连接。App Secret 只填本机密码框。

应用在飞书后台拥有接口权限后，还需要被加入这张多维表格的文档应用并获得相应权限。若已连接现有企业技能库，应使用管理员提供的表格信息，避免另建一套不相关的库。

## 飞书首次接入

本节供企业管理员或首次接入的维护人员操作。已有可用连接的普通用户可以跳过。

### 第一步 创建应用并授权

1. 进入飞书开发者后台，创建企业自建应用。在「凭证与基础信息」取得 App ID 和 App Secret。

2. 按项目采用的「添加文档应用」方式配置机器人能力，开通字段读取、记录读取、新增、更新、删除，以及文档素材上传和下载所需权限。按后台要求完成发布或审批。

3. 创建专用空白多维表格。通过表格右上角的菜单进入「添加文档应用」，添加该应用并授予可编辑。启用高级权限的表还需按企业角色进一步授权。

[飞书开发者后台](https://open.feishu.cn/app)

### 第二步 准备表头

建议按下面的字段建表。「名称」作为主字段，「技能包附件」使用附件类型，其余 11 个字段使用文本或多行文本。

名称、Skill ID、简介、分类、标签、状态、来源链接、版本、内容哈希、更新时间、Skill 正文、技能包附件。

仅创建字段即可。已有数据表先检查字段映射，修改列名或字段类型前先备份。

### 第三步 在本机填写并测试

1. 打开目标数据表，复制含 /base/ 的原始表格链接。网址里的 table= 后面是 Table ID。若拿到的是 /wiki/ 链接，先在飞书打开原始表格再复制。

2. 打开工作台「设置与诊断 → 飞书多维表格」，填写 App ID、App Secret、「多维表格 App Token / 表格链接」和「数据表 Table ID」。

3. 点击「保存全部设置」，再点「验证凭证与读取权限」，核对目标表及字段兼容结果。

4. 按需要点击「新增测试记录并验证写权限」。这一步会写入明确标记的测试记录并尝试清理，需检查返回的清理结果。

5. 用一份已经审阅的个人技能做首次同步，再次预览应能识别内容一致；从企业端导入个人副本后，核对正文和附属文件。

App ID 属于开放平台应用。App Token 属于多维表格。Table ID 属于具体数据表，这三项需要分别填写。平台权限名称和发布要求可能调整，应以飞书当前后台和官方接口说明为准。

## 日常启动与常见问题

### 以后每天怎样打开

Windows 双击项目文件夹里的「一键配置并启动.cmd」。Mac 在项目目录运行 bash scripts/start.sh。然后打开 http://127.0.0.1:8765，使用期间保留启动窗口。这个地址只指向当前电脑，每台电脑都需要在本机启动项目。

### 更新 Windows 时沿用原资料

1. 先停止旧工作台，保留原项目和资料文件夹。把新安装包解压到另一个新文件夹。

2. 第一次双击新文件夹中的「沿用旧资料并启动.cmd」，在目录选择窗口中选择原项目文件夹，或原来的 data 资料文件夹。

3. 进入工作台确认版本为 v0.2.5，并核对个人技能、任务和模型配置。以后使用普通一键入口。资料继续保存在原位置，原文件夹仍需保留。

### 遇到问题先检查什么

| 看到的情况 | 先这样处理 |
| --- | --- |
| 浏览器打不开 | 确认本机启动窗口仍在运行，核对地址和端口；安装失败时先处理窗口里的错误。 |
| 页面像旧版 | 刷新或重新打开页面，核对按钮名称和安装包日期。更新 GitHub 源码后仍需重新安装构建并启动。 |
| 抖音自动获取失败 | 查看失败阶段和错误原因，检查网络及采集依赖；可稍后重试或补充有权使用的视频、字幕。 |
| 模型认证或额度错误 | 核对相应能力的地址、模型名、API Key 和账户权限，保存后单独测试。 |
| 飞书读取或上传失败 | 检查应用权限、目标表授权和字段类型；查看逐项结果，重新预览后再同步。 |

### 资料保护与求助

资料默认放在项目的 data 文件夹。更换电脑或删除项目之前，先安排备份。完整备份与恢复可按仓库「安装与数据」说明由维护人员操作；恢复到新目录后需要重新填写模型和飞书密钥。

向维护人员说明系统类型、安装包日期、操作步骤和错误文字。截图时遮住密钥和私人材料。保留原资料目录，方便排查和恢复。

[项目安装与资料备份说明](https://github.com/baizhanwen/liming-zhiyao-skill-collect/blob/main/docs/安装与数据.md)
