# 技术决策与来源（2026-10-26）

采用施工书推荐栈。锁定的实际版本见 `uv.lock`、`requirements.txt` 和 `frontend/package-lock.json`，而非依赖本文猜测最新版。

- 本机系统 Python3.9 不满足，使用已安装的 Python3.12.14 隔离环境；发布要求 Python3.11+。
- [FastAPI 发布记录](https://fastapi.tiangolo.com/release-notes/) 核对后解析到0.162.0；后端不使用实验分布式队列。
- [Vite 官方入门](https://vite.dev/guide/) 要求 Node20.19+/22.12+；本机Node24.19.0。
- [React 官方版本](https://react.dev/versions) 与 npm registry 确认稳定包，再锁实际安装结果。
- [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) 核对 messages/image_url/response_format；采用兼容协议而非保证所有厂商相同能力。提供 JSON mode 开关。
- [Transcriptions](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create) 核对 multipart file、model、json text；每120秒音频分段，保留段起点。默认20分钟/100MB。
- [GitHub REST 搜索](https://docs.github.com/en/rest/search/search) 有 Token 时代码搜索，无 Token 时真实仓库搜索并标降级。
- 抖音只读取公共分享页的明确媒体地址，经每次解析/重定向公共IP检查和连接IP固定；不绕登录和反爬，不依赖计费解析服务。官方授权接口并非任意公开视频下载 API。
- [Easel 展示](https://zjureal.com/Easel/) 只参考浅色、留白和工作台信息层次；没有复制其源码、图片、商标和设计素材。来源分析固定版本单列保存，不执行该仓库脚本。

凭证使用 Fernet 加密，与SQLite分离；本机密钥文件限制权限。它防止凭证出现在数据库/普通备份中，不保护已被同一系统账户控制的主机。普通备份不含密钥和密文，恢复后需重配凭证。
