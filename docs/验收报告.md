## 可复现命令

本次本机结果：**87 passed**（4.36秒）；上游Starlette对httpx测试客户端给出1条弃用警告。前端生产构建通过；Chrome实际业务验收1个串行用例/10组检查通过（7.3秒），不是只检查页面能打开。

```sh
uv sync --frozen
uv run --frozen pytest -q --junitxml=artifacts/verification/pytest.xml
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix frontend run test:ui
.venv/bin/python scripts/verify_recovery.py
.venv/bin/python scripts/doctor.py --json
.venv/bin/python scripts/check_release.py --output artifacts/verification/release-scan.json
```

UI验收使用新临时数据目录与8766端口，测试自行编写的样例，并调用真实本地后端，不拦截API伪造成功。默认使用已安装Chrome；可用 `PW_CHANNEL=chromium` 指定Playwright Chromium（需先 `npx --prefix frontend playwright install chromium` 或进入frontend执行 `npx playwright install chromium`）。测试报告保留“未配置”结论。

## 待接入条件与真实复验步骤

不要在聊天中发送密钥；在本机 `http://127.0.0.1:8765` 的设置中配置。

1. 文字/视觉/转写分别填供应商Base URL、准确模型名及自己的API Key，分别探测；会产生自己供应商定义的费用。使用Easel来源、实际授权视频和SRT运行任务，人工核对证据与输出。填写A02/A03分析/A06实际结果，不能只以探测成功替代质量验收。
2. 提供一个已授权企业自建应用及目标Bitable表，确认应用接口权限和文档访问权限；配置字段映射，正文等用文本、包用附件。先读测试，再新建有标记的写权限测试记录，检查清理结果。
3. 使用单独验收技能执行新增→读取完整附件→修改更新→重复noop；再分别修改本地/飞书正文，预览冲突并选择版本，核对包、版本、映射及日志。只在真实表实测后将A09/A10改为通过。
4. 抖音网络需要返回合法公网目标；若平台限制仍不能获取，保留获取失败结论。使用合法持有的视频或真实字幕补到原任务，分别记录自动获取和补传分析两项，不绕过访问限制。
