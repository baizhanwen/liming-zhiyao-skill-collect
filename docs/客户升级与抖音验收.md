# 客户从0.2.2升级并分析抖音链接

本补丁面向已经安装0.2.2或0.2.3、已配置模型的Windows电脑。采集在本机完成，没有新增付费解析服务。GitHub、飞书和模型配置继续使用原设置。

## 升级一次

1. 关闭旧项目的启动窗口，释放8765端口。保留原项目文件夹。
2. 将Windows升级包完整解压到另一个临时文件夹，双击其中的`升级并启动.cmd`。
3. 在弹出的选择框中选原项目文件夹，即含`backend`、`frontend`、`pyproject.toml`和`.venv`的文件夹。不要选`data`文件夹。
4. 升级器核对文件校验值，备份将替换的旧代码，再更新和启动。浏览器刷新后，左下角应显示`v0.2.3`。

补丁只包含固定代码、版本元数据和已构建页面，不包含数据库、模型密钥、Cookie或视频；不修改`data`、`uploads`、`tasks`及本地凭证文件。它复用原Python/Node环境。若校验、项目版本、路径或占用检查失败，按窗口提示处理，不要复制私人数据给别人。

## 平时分析

在工作台粘贴抖音复制出的整段分享文案，点击“分析”。不用先打开抖音网页或运行下载脚本。项目会自动解析目标、获取原片、转写音频、分析抽样画面和保存知识；若材料提到GitHub项目，会自动检索并显示候选。

“已收到网页响应”不表示原片已获取；看到“音画材料分析完成”和保存的分析、来源证据才算该任务完成。名称搜索候选需要核对，不能仅因排第一就断言是视频中的项目。

## 这次请客户确认

- 版本为0.2.3，原模型、GitHub及飞书配置仍在。
- 提交此前失败的同一段分享文案，任务实际完成，并出现转写/抽样画面证据及知识记录。
- 若失败，在任务的技术详情或“设置与诊断”记录错误阶段和脱敏诊断；不用发送密钥、Cookie、验证码或私人视频。
