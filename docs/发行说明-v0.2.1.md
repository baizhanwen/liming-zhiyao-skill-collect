本次修复任务长时间处理时缺少可见状态的问题。工作台分别显示当前阶段、任务及步骤用时、实际返回的计数、最近真实活动、状态刷新时间和工作线程状态。首页与任务详情独立轮询；断连或状态读取超时保留上次任务结果并提示重连，不将刷新失败改成任务处理失败。切换任务、重复打开同一任务和迟到响应均有保护。

GitHub 读取可报告元数据、目录、所选文件检查与匿名公开 Git 回退。检查数量只在读取实际返回后推进，已纳入文件数不包含无法读取或超出上下文范围的文件。浏览器采集分别显示来源响应、网页代理总流量、实际取回数据与完整媒体组件；网页流量、页面标题或浏览器安装均不代表已经取得原片。媒体准备只在实际检查、分段或抽帧返回后更新计数。

文字、转写和视觉服务采用非流式请求，界面仅显示正在等待服务响应及已经保存的结果数量，**不编造供应商生成百分比、剩余时间或模型内部进度**。长时间没有新活动只提示等待较久，不能据此判断卡死。状态 GET 不写入数据库，不制造活动心跳；重复计数不更新最近活动。取消会停止后续阶段，在途请求尚未结束时继续明确显示等待；不会把软取消当作已经强制中断远端请求。

进度只接收固定阶段与非负整数白名单，不接收 URL、文件路径、标题、Cookie、签名或供应商原始载荷。旧运行、旧步骤以及重试前的迟到回调不能覆盖当前进度。普通观测或观测存储失败不会改变业务结果或触发额外模型重试；显式取消信号继续传播。服务中断时尚未确认结果的模型阶段仍需手动继续，原有检查点、有限重试和来源安全约束保持。
