## 技术与验收边界

- React / TypeScript / Vite，Python 3.12 / FastAPI / SQLite FTS5；单用户本机回环服务、受控任务线程和持久化检查点。
- 用户配置各能力的模型及企业凭证；凭证仅留本机，不进入 Git、普通备份或公开验收材料。
- 没有模型可启动管理资料；抖音获取受限可在原任务补传；没有视觉时明确说明未分析画面；FFmpeg 缺失只影响媒体。
- A01—A13 分别记录本地、显式契约、真实服务与发布，不由页面可打开或接口探测代替业务流程。
