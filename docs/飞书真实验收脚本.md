# 飞书真实验收脚本

脚本：`scripts/verify_feishu_live.py`。当前脚本第三轮已在用户授权专用表完成 18 步真实验收，完整包、去重、双向冲突、多副本保护与受限清理全部通过；公开结果见 `artifacts/verification/feishu-live.json`。前两轮实际失败及清理证据按内容摘要归档保留，原因和修复见 `docs/验收报告.md`。此结果限定本次配置与自编夹具；重新执行仍需核对目标并会实际写入。

在已启动的本机工作台中配置目标专用表、字段映射及 App Secret。Secret 只填本机设置，不放命令参数或环境变量。本次验收使用当前配置的企业技能 Table ID，不操作同一 Base 内的其他表、仪表盘或工作流。原有全空占位记录会保留。

## 审阅与执行

默认只展示计划，不发请求：

```sh
.venv/bin/python scripts/verify_feishu_live.py
```

读取本机配置布尔和目标摘要，不调用飞书：

```sh
.venv/bin/python scripts/verify_feishu_live.py --check-config
```

确认 `secret_configured=true`，记录返回的 `target_sha256`。审阅脚本及目标后执行（下方占位值替换为上一步的 64 位摘要）：

```sh
.venv/bin/python scripts/verify_feishu_live.py --run --expected-target-sha256 '<上一步的目标SHA256>'
```

默认本机地址为 `http://127.0.0.1:8765`，需要时用 `--base http://127.0.0.1:端口` 指定。真实运行会向当前专用表写入、更新、上传附件及删除本次创建的验收记录；不调用任何模型，也不运行技能文件。

## 验证范围与清理边界

脚本创建唯一随机标记的自行编写技能，含 `SKILL.md`、参考文本和 256 字节二进制文件。验证：认证与字段类型、独立写测试及删除、首次上传、重复无需同步、真实附件下载及逐文件哈希、个人更新、企业正文直接修改、只读导入后的附件过期提示、显式刷新、双边冲突阻断、保留个人和企业版本、三份正文与完整文件一致、稳定企业 Skill ID 和同步日志。另建个人副本的读取验收放在最后，不自动上传该副本；随后验证企业直接导入因多个关联副本而明确拒绝、双方内容均不变，再只从 primary 选择企业版本，核对只更新 primary、另一个副本保留，完整附件及稳定企业 ID 一致。

远端修改/删除同时要求：该记录不属于执行前基线，Skill ID 等于本次自行创建的随机本地技能 ID，正文含本次完整唯一标记。不会按名称批量删除，不会清空表，不会修改原有空行或其他技能。失败后仍尝试清理；本机验收技能默认归档，保留版本和同步审计记录。删除的是验收记录及其附件关联；飞书底层素材保存期限由平台控制，脚本不申请额外全局云盘删除权限。

目标摘要和字段映射在流程中持续核对，配置变化会停止操作。流程结束还会比较所有执行前记录的实际字段哈希；若用户或其他程序同时修改了原记录，会报告差异，脚本不会尝试回滚这些修改。

## 证据与失败后恢复

- 公开安全结果：`artifacts/verification/feishu-live.json`。只含脱敏步骤结果、文件/目标摘要和时间，不含表链接、App ID、Token、Record ID 或企业正文。
- 私有状态、目标标识、Record ID、清理清单和本次自行编写的实际下载包：`artifacts/private/feishu-live-<运行号>/`，已被 Git 忽略；状态文件权限在 macOS/Linux 下为 0600。
- 控制台不打印密钥、目标标识或接口原始响应。非预期失败时，会在清理前把本次自身技能的 preview、本地/远端字段原始形态与规范化结果、基线和实际附件写入私有诊断文件，便于定位真实服务差异；不保存其他企业记录的正文。只有全部业务步骤与清理都完成时才输出 `status=passed`。

若清理失败，保留私有 `state.json`；恢复原目标配置后，只重试本次清理：

```sh
.venv/bin/python scripts/verify_feishu_live.py --cleanup-state 'artifacts/private/feishu-live-运行号/state.json' --expected-target-sha256 '<原目标SHA256>'
```

清理重试不重新做模型或同步业务，也不会把原来失败的业务验收改成通过。私有清单只在原专用表上生效；若所有权标记已被移除，脚本拒绝删除，需要维护者人工核对。

业务 API 遇网络超时不会由验收脚本盲目重试；生产同步服务有自己的创建意图与去重检查。应先核对私有记录及清理状态，再决定是否新跑一轮。真实企业读取/写入、视觉/转写及其他能力均独立记录，不由本脚本替代。
